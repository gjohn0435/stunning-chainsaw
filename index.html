Exploring Neo-Brutalist Web Design

Neo-Brutalism rejects polish. It embraces rawness. It shows structure honestly. No subtle shadows. No smooth transitions. Just function and form, exposed and unrefined.

WHAT IS NEO-BRUTALISM?

ORIGINS

Inspired by Brutalist architecture (1950s-1970s), Neo-Brutalism brings raw concrete aesthetics to digital design.

PHILOSOPHY

"Truth to materials" - show what things really are. Don't hide structure. Reject corporate polish.

REBELLION

Anti-establishment, punk ethos. Deliberately rough. Purposefully ugly. Functionally minimal.

KEY CHARACTERISTICS

THICK BORDERS

3-5px black borders around everything

HARD SHADOWS

8px offset shadows, no blur

SYSTEM FONTS

Arial, Courier, Helvetica only

BLACK & WHITE

Stark contrast, bright accents

ALL CAPS

Headings shout, no subtlety

NO TRANSITIONS

Instant state changes only
