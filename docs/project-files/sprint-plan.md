# Sprint Plan - Neo-Brutalism Design Gallery
## Swiss Design Lineage Vibe Coding Project

**Style:** Neo-Brutalism
**Total Time:** ~10 hours over 7 days
**Started:** November 21, 2025

---

## Sprint 1: Foundation (2 hours) - Days 4-5

### Goal
Establish core Neo-Brutalist visual system and homepage structure.

### Tasks
1. **Layout Structure**
   - Create boxy, compartmentalized sections
   - Add thick borders (4-5px black) around all major sections
   - Expose grid structure visibly
   - Implement tight, packed spacing

2. **Typography System**
   - System fonts: Arial for headings, Courier for code elements
   - H1: 72px, ALL CAPS, bold, line-height 1.2
   - H2: 48px, ALL CAPS, bold
   - Body: 18px, line-height 1.4
   - Links: underlined, uppercase

3. **Color Palette**
   - Black (#000000) - primary
   - White (#FFFFFF) - backgrounds
   - Yellow (#FFFF00) - accent/buttons
   - Red (#FF0000) - warnings/alerts
   - High contrast throughout

4. **Component Foundation**
   - Hard shadows (8px 8px 0 #000)
   - No border-radius (sharp 90° angles)
   - Instant state changes (no transitions)

### Success Criteria
- [ ] Layout matches Neo-Brutalist reference structure
- [ ] Typography uses system fonts with tight line-height
- [ ] Colors are stark black/white with bright accents
- [ ] Desktop view looks deliberately raw and unrefined
- [ ] Thick borders visible around all sections
- [ ] Iterated 2-3 times from first output

---

## Sprint 2: Components (2 hours) - Day 5-6

### Goal
Build all interactive components with authentic Neo-Brutalist styling.

### Tasks
1. **Navigation System**
   - Black background, white text
   - Thick red bottom border (5px)
   - Uppercase links with underlines
   - No smooth transitions

2. **Cards/Content Blocks**
   - White background
   - 4px black borders
   - Hard offset shadows (8px 8px 0 #000)
   - Minimal padding (16px)
   - Packed content

3. **Buttons & Interactive Elements**
   - Bright yellow background
   - Black text, uppercase
   - 3px black borders
   - Hard shadow (4px 4px 0 #000)
   - Instant hover (shadow shift)

4. **Footer**
   - Black background
   - White text
   - Thick top border
   - Minimal decoration

### Success Criteria
- [ ] All components match Neo-Brutalist aesthetic
- [ ] Navigation feels raw and functional
- [ ] Interactive elements have hard shadows and instant state changes
- [ ] Components work on mobile (still raw, just responsive)
- [ ] No smooth animations anywhere
- [ ] Iterated 2-3 times

---

## Sprint 3: Polish & Complete (2 hours) - Day 6-7

### Goal
Complete all pages, ensure responsiveness, and achieve quality standards.

### Tasks
1. **Complete All Pages**
   - Homepage (hero, about preview, style showcase)
   - Timeline page (Neo-Brutalism history)
   - Designers page (key practitioners)
   - About page (style explanation)

2. **Responsive Refinement**
   - Desktop (1920px): Full boxy layout
   - Tablet (768px): Stacked sections, maintain borders
   - Mobile (375px): Single column, keep brutalist aesthetic
   - Maintain thick borders at all sizes
   - Keep tight spacing on all devices

3. **Final Content**
   - Meaningful information about Neo-Brutalism
   - Authentic historical context
   - Clear examples and references
   - Process screenshots integrated

4. **Quality Assurance**
   - Lighthouse Performance 90+
   - Lighthouse Accessibility 90+
   - Lighthouse Best Practices 90+
   - Lighthouse SEO 90+
   - All links functional
   - No console errors

### Success Criteria
- [ ] All 4 pages complete and consistent
- [ ] Works perfectly on desktop/tablet/mobile
- [ ] Lighthouse 90+ on all metrics
- [ ] Feels raw and professional simultaneously
- [ ] Authentically Neo-Brutalist throughout
- [ ] Screenshot comparison shows clear transformation from Swiss design
