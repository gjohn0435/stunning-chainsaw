## Why Neo-Brutalism?

**Reasons for choosing this style:**
1. Strong visual transformation from Swiss design
2. Distinctive, contemporary aesthetic
3. Clear design principles (raw, honest, anti-corporate)
4. Interesting reaction against Swiss refinement
5. Demonstrates understanding of design movements

## Reference Examples

### Primary References

#### 1. Brutalist Websites (brutalistwebsites.com)
**Source:** The definitive collection of Neo-Brutalist web design
**Key Characteristics Observed:**
- Stark black/white color schemes
- Thick borders (3-5px) around all elements
- Hard, offset shadows (not subtle)
- System fonts (Arial, Courier)
- ALL CAPS typography for headings
- Tight, packed spacing
- Raw, unrefined aesthetic

#### 2. Balenciaga Digital Presence
**Source:** High fashion brand using Brutalist web aesthetics
**Key Characteristics Observed:**
- Black background with white text
- Minimal color usage
- Raw typography
- Anti-corporate polish
- Functional, no-nonsense navigation

#### 3. Bloomberg Businessweek
**Source:** Corporate site with Brutalist influences
**Key Characteristics Observed:**
- Bold, large typography
- High contrast layouts
- Unrefined aesthetic
- Clear information hierarchy despite rawness

#### 4. Washington Post 2016 Election Site
**Source:** Data-driven Brutalist design
**Key Characteristics Observed:**
- Black/white/red palette
- Raw data presentation
- Minimal decoration
- Functional minimalism

### Design Elements to Implement

**Color Palette:**
- Primary: Black (#000000), White (#FFFFFF)
- Accent: Bright Yellow (#FFFF00), Red (#FF0000)
- No gradients or subtle variations

**Typography:**
- System fonts: Arial, Courier New
- Headings: 60-72px, ALL CAPS, bold
- Body: 16-18px
- Line-height: 1.2-1.3 (tight)

**Layout:**
- Thick borders: 4-5px solid black
- Hard shadows: 8px 8px 0 #000000
- No border-radius (sharp 90° angles)
- Tight spacing (minimal padding)
- Exposed grid structure

**Components:**
- Buttons: Bright backgrounds, thick borders, hard shadows
- Cards: White background, thick black borders, offset shadows
- Navigation: Black background, white text, uppercase, underlined links

## Key Differences from Swiss Design

| Swiss Design | Neo-Brutalism |
|--------------|---------------|
| Invisible grid | Visible, exposed grid |
| Generous white space | Tight, packed spacing |
| Refined typography | Raw, ALL CAPS headings |
| Minimal, refined colors | Stark black/white + bright accents |
| Thin/no borders | Thick (3-5px) black borders |
| No/subtle shadows | Hard, offset shadows |
| Professional elegance | Raw, rebellious honesty |

## Notes & Observations

**What makes Neo-Brutalism authentic:**
- Deliberately rough (not accidentally amateur)
- Anti-corporate (a brand would reject it)
- Honest about structure (shows the "bones")
- Functional minimalism (no unnecessary decoration)

**Common mistakes to avoid:**
- Making it too pretty (subtle shadows, rounded corners)
- Using too many colors (should be stark)
- Generous white space (should be tight)
- Smooth animations (should be instant, hard)
- Hiding the structure (should expose grid)
