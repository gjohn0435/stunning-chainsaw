### Iteration 1: Tighter Spacing & Enhanced Brutalism

**Date:** November 21, 2025
**Focus:** Typography, spacing, and visual rawness

**Changes Made:**

1. **Typography Refinements:**
   - Body line-height: 1.4 → 1.3 (tighter, more packed)

3. **Border Enhancements:**
   - Hero description border: 3px → 4px
   - Section title border: 4px → 5px

4. **Shadow Additions:**
   - Added hard shadow to hero description (5px 5px 0)
   - Added hard shadow to section borders (10px 10px 0)
   - Added hover state to char-box with instant shadow shift
   - Added hard shadow to footer title (4px 4px 0 white)

5. **Structural Honesty:**
   - Added exposed grid lines (vertical center line on sections)
   - Added corner accents to comparison items (black squares)
   - Red corner accent for highlighted comparison item
   - Inner shadow on footer for depth

6. **Visual Rawness:**
   - Footer title now has bordered box treatment
   - Character boxes have instant hover transform (no transition)
   - Reduced min-heights for tighter layouts
   - All z-index positioning for proper layering
